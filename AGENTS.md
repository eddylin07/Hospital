# Agent Instructions

## Project

- Name: Hospital
- Stack: Java, Spring Boot 2.0, MyBatis, Freemarker, Maven, MySQL
- Description: Medical information management system.

## Working Rules

- Read `AGENTS.md` and `MEMORY.md` before making project changes.
- Keep fixes minimal and focused on concrete correctness or security issues.
- Prefer existing Spring/MyBatis patterns in this repository.
- Run focused tests when changing behavior; run broader Maven tests when feasible.
- Do not record secret values in project memory.
