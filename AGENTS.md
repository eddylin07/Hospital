# Agent Instructions

## Project

- Name: Hospital
- Stack: Java, Maven, Spring Boot 2.0, MyBatis, Freemarker.

## Working Rules

- Follow existing source and test conventions.
- Prefer focused tests over broad refactors.
- Keep tests deterministic and independent of external services where possible.
- Do not commit secrets or credentials.

## Validation

- Run the relevant Maven test target for changed areas.
- If a test cannot run because of the environment, record the reason in the handoff.
