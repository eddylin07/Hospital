# Agent Instructions

## Project

- Name: Hospital
- Purpose: hospital / medical information management system
- Stack: Java, Spring Boot 2.0.0.RELEASE, MyBatis, FreeMarker, Maven, MySQL

## Working rules

- Read `MEMORY.md` before making project changes.
- Keep changes scoped and prefer existing controller/service/mapper patterns.
- Do not commit generated IDE files or local runtime artifacts.
- Treat credentials and database contents as sensitive; record only locations, never secret values.

## Testing

- Prefer targeted Maven commands for verification.
- If dependencies or old Java compatibility prevent a full build, capture the exact failure and run the narrowest feasible checks.
