# HospitalAction Agent Notes

## Project

- Project name: HospitalAction
- Stack: Java, Maven, Spring Boot 2.0, MyBatis, Freemarker, MySQL
- Default working directory: repository root

## Workflow

- Read `MEMORY.md` before making project changes.
- Keep changes minimal and scoped to the requested behavior.
- Prefer existing Spring MVC, service, mapper, and template patterns already used in the project.
- Do not store credentials or secret values in this file or in `MEMORY.md`.

## Validation

- For Java code changes, run the most focused Maven test command available.
- If focused tests are unavailable, run `mvn test` when dependency setup permits.
