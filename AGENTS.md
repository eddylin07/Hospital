# Hospital Agent Notes

## Project

- Name: Hospital
- Description: Medical information management system.
- Stack: Java, Spring Boot 2.0.0, MyBatis, FreeMarker, MySQL, Maven.

## Working Guidelines

- Prefer small, behavior-focused changes with targeted validation.
- Use Maven commands from the repository root for build and test checks.
- Keep credentials out of this file and record only credential locations when needed.

## Useful Commands

- `mvn test`
- `mvn -DskipTests package`
